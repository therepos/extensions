# extensions

Browser tools for web apps with no API: userscripts (`*.user.js`) and the MyHub Edge/Chrome extension (`myhub/`).

- Userscripts: install the `.user.js` in a userscript manager; it self-updates from this repo.
- MyHub extension: download `myhub-setup.zip` from the latest `myhub-v*` [release](https://github.com/therepos/extensions/releases), unzip and double-click `myhub-setup.cmd`. Run it again to update.

See `AGENTS.md` for conventions and tests.
